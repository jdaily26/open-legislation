# Rebuttals

School District AI Purchasing Reports Act · Bill v1.0

## Scope and workload

- **Does this make schools buy AI?** The bill requires a report on covered purchases and leaves buying and access decisions with districts.
- **Why file every quarter?** A quarterly return catches pilots, renewals, and tools dropped midyear while boards can still use the information.
- **Will small districts have to start from scratch each time?** The state provides the last return for updates and districts can certify it when nothing, including payments, changed.
- **Why include a disabled feature?** Its presence and disabled status are useful facts for the next renewal.

## Cost and privacy

- **Does the whole software bundle count as AI spending?** The district reports the bundle payment separately and marks the AI share unknown unless purchase records identify it.
- **Does reporting expose student or teacher information?** The return uses roles or grade bands and omits names, individual identifiers, prompts, and student or personnel records.
- **What if a district misses the deadline?** The state gives the district 30 days after notice to file or correct the return and refers unresolved filings to the superintendent.
